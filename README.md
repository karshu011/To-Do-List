# To-Do-List
# 📝 To-Do List App

A simple and interactive To-Do List application developed using HTML, CSS, and JavaScript. It helps users manage their daily tasks and stay organized.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks
- 📋 Display all tasks
- 🔔 Show task saved successfully message
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

To-Do-List/

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter your task and click the Add button.

5. Manage your daily tasks easily!
